# Mapa temario → funcionalidades de la app MyMoney

| Área del temario | Funcionalidad candidata en la app |
|---|---|
| Ingresos, gastos y ahorro (mód. 4, 20) | Registro y categorización de movimientos, tasa de ahorro, presupuesto mensual |
| Balance, activos, pasivos, patrimonio neto (mód. 4, 5) | Balance personal, patrimonio neto histórico, "foto financiera" |
| Fondo de emergencia, riesgos y coberturas (mód. 4) | Objetivo de fondo de emergencia (meses de gasto), seguimiento de progreso |
| Objetivos financieros y plan (mód. 4) | Objetivos con plazo e importe, plan financiero, checklist de acción |
| Valor temporal, interés compuesto, CAGR, TIN/TAE, VAN/TIR (mód. 3) | Calculadoras y simuladores; rentabilidad total, CAGR, TIR/XIRR por cartera |
| Inflación e impuestos, rentabilidad neta (mód. 3, 7) | Rentabilidad real y neta de impuestos |
| Riesgo: volatilidad, VaR, CVaR, drawdown, Sharpe (mód. 3, 14, 16) | Métricas de riesgo de cartera, drawdown máximo, ratio de Sharpe |
| Clasificación de activos y vehículos (mód. 6) | Taxonomía de activos: liquidez, RV, RF, oro, inmuebles, cripto, PE; tipo de vehículo (fondo, ETF, plan de pensiones, PIAS, cuenta, depósito) |
| Liquidez: cuentas, depósitos, monetarios, garantías (mód. 7) | Control de límites del Fondo de Garantía (100.000 €/entidad), comparador cuenta/depósito/monetario |
| Renta fija: precio, rentabilidad, riesgos (mód. 9) | Seguimiento de bonos: cupón, vencimiento, TIR |
| Financiación, hipotecas, amortización anticipada (mód. 10) | Simulador de hipoteca y préstamo, amortización anticipada, bonificaciones, ratio de endeudamiento |
| Inmuebles: rentabilidad bruta/neta (mód. 22) | Ficha de inmueble con rentabilidad, gastos, financiación y cashflow |
| Fiscalidad del ahorro, IRPF, Patrimonio, modelos 720/721 (mód. 11–13) | Plusvalías/minusvalías realizadas, ganancias por FIFO, avisos de modelo 720/721 y de plazos fiscales, estimación de IRPF del ahorro |
| Construcción de carteras, correlación, asignación estratégica vs táctica (mód. 14–17) | Asset allocation objetivo vs real, correlaciones, escenarios y stress test |
| Rebalanceo y aportaciones periódicas (mód. 20) | Alertas de desviación, asistente de rebalanceo paso a paso, plan de aportaciones automáticas |
| Selección de fondos (Morningstar, KID, comisiones/TER) (mód. 6, 18, 21) | Ficha de producto: ISIN, TER, categoría, riesgo (SRI) |
| Operativa con brókers (MyInvestor, IBKR/MEXEM, Bit2Me) (mód. 19) | Importación de operaciones por bróker/exchange, multicuenta |
| Riesgo conductual y sesgos (mód. 2, 8, 16) | Mensajes de buenas prácticas, diario de decisiones |
| Control patrimonial con IA / asesor personalizado (Masterclass) | Asistente IA sobre los datos del usuario |
